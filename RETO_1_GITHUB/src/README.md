# Código fuente de la aplicación

Esta carpeta tiene una copia de los archivos de aplicación principales para poder revisarlos rápido desde GitHub:

- `start.s`
- `baseclock.s`
- `GPIOconf.s`
- `GPIOset.s`

El proyecto ejecutable original se conserva completo en `project/RETO_1/` para no alterar las rutas y configuración de SEGGER Embedded Studio.

`GPIOset.s` no participa en el enlace y su implementación está incompleta; se conserva por trazabilidad del material original.
